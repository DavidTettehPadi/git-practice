# git-practice Instructions

## Project

This is a small JavaScript project used to practice Git workflows.

## Source

- The primary source file is `index.js`.
- Keep its existing plain `console.log(...)` style unless asked otherwise.
- Do not modify `.env`.

## Verification

After changing JavaScript, run:

```bash
node index.js
```

## Git Safety

- Keep changes limited to the files requested.
- Inspect `git status` and `git diff` before staging or committing.
- Do not stage, commit, merge, rebase, reset, or push unless explicitly requested.
- When resolving a merge conflict, preserve only the content the user approves and remove all conflict markers before staging.
